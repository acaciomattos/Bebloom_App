# English Tutor Demo

English Tutor Demo is a Flutter MVP focused on self-study for English students.
The app loads lesson content from local JSON assets, stores progress locally,
and provides a simple study flow with lessons, exercises, saved vocabulary,
and progress tracking.

## Current MVP

- Home screen with continue studying shortcut
- Lesson library with module, level, and skill visibility
- Lesson detail screen with explanation, examples, vocabulary, and exercises
- Exercise feedback with local result tracking
- Saved vocabulary list
- Progress overview
- Local persistence with SharedPreferences
- Avatar placeholder prepared for future replacement

## Run

```bash
flutter pub get
flutter run
```

To target Android specifically:

```bash
flutter devices
flutter run -d <android-device-id>
```

## Quality Checks

```bash
flutter analyze
flutter test
```

## Notes

- This version does not use backend, Firebase, login, payments, or external APIs.
- Lesson content is currently authored in `assets/content/lessons.json`.
- The Android project now follows the Kotlin DSL files generated by Flutter in `android/`.
